# 🏦 Bank Management System

A simple Bank Management System built using Python and JSON.

## 🚀 Features
- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- View Account Details
- JSON File Storage

## 🛠️ Technologies Used
- Python
- OOP
- JSON
- File Handling
